# 홈 화면 요구사항 문서

홈 화면은 사용자가 서비스에 진입했을 때
- 본인과 관련성이 높은 티노인 QnA
- 새롭게 올라오는 질문 흐름
- 본인과 관련된 티노스토리 모집글

을 한 번에 볼 수 있는 **개인화 대시보드 역할**을 한다.

본 서비스는 **로그인하지 않으면 사용할 수 없다.**  
홈 화면 진입 시점에는 항상 로그인된 사용자라는 전제를 둔다.

---

## 1. 홈 화면 구조 개요

홈 화면은 크게 세 영역으로 구성한다.

1. 상단: 나와 관련된 티노인 **주목 질문 카드 영역**
2. 중간: **새로 올라온 질문 리스트**(티노인)
3. 하단: **추천 티노스토리 카드 영역**

---

## 2. 상단 – 티노인 주목 질문 카드

### 2.1 목적

- “지금 주목받는 QnA 중, 나와 관련된 것”을 빠르게 보여준다.
- 사용자가 홈에 들어오자마자, 참여 가치가 높은 질문들을 확인하고 바로 들어가도록 유도한다.

### 2.2 노출 형식

- 카드 슬라이드(캐러셀) 또는 가로 스크롤 카드 리스트 형태
- 한 번에 3개 또는 5개 노출 (정확한 개수는 UI/UX에서 결정)
- 각 카드에는 다음 정보 표시:
  - 질문 제목
  - 말머리(카테고리) / 전공 / 태그 일부
  - 요약(본문 일부)
  - 추천 수, 답변 수, 조회수
  - “왜 이 질문이 보이는지”에 대한 설명 텍스트

### 2.3 주목 질문 선정 기준

주목 질문은 다음 두 가지 유형을 우선으로 구성한다.

1. **단기간에 많은 추천을 받은 질문**
   - 예시 기준:
     - 최근 24시간/48시간 내 등록
     - 추천 수가 일정 기준 이상(예: 5개 이상)
     - 최근 증가 속도가 빠른 질문(트렌딩 질문)
   - + “나와 관련성” 필터를 적용 (아래 2.4 참고)

2. **나와 같은 학부(또는 전공)의 주목 질문**
   - 사용자의 전공/학부 정보 기반
   - 동일 학부/전공 태그가 달려 있거나, 전공 필드가 동일한 질문 중
   - 추천 수, 조회수, 답변 수가 높은 순으로 선정

### 2.4 “나와 관련된”의 정의

주목 카드에 노출되는 질문은 **다음 조건 중 하나 이상을 만족하면** “나와 관련 있음”으로 간주한다.

- 내 전공/학부와 일치하는 전공/학부가 설정된 질문
- 내가 관심사로 설정한 태그와 겹치는 태그를 가진 질문
- 내가 이전에 많이 본/북마크한 태그와 유사한 태그를 가진 질문
- 내 학년과 관련된 말머리/태그(예: 졸업, 인턴, 1학년, 기초과목 등)

초기 버전에서는 전공/학부 + 관심사 태그 정도까지로 단순하게 시작하고,  
추후 유저 행동 기반으로 개인화 로직을 고도화한다.

### 2.5 “왜 이 질문이 보이나요?” 표시

각 카드에는 간단한 이유를 노출한다.

- 예시:
  - “같은 학부 학생들이 많이 보고 있는 질문이에요”
  - “최근 24시간 동안 추천이 급격히 늘어난 질문이에요”
  - “회원님 관심사 태그(#웹개발)와 관련된 질문이에요”

이 문구는 규칙 기반 텍스트로 처리한다.

---

## 3. 중단 – 새로 올라온 질문 리스트 (티노인)

### 3.1 목적

- 전체 커뮤니티에서 **지금 막 올라오는 질문 흐름**을 보여주고,
- 사용자가 빠르게 질문을 소비·답변하도록 유도한다.

### 3.2 기본 동작

- 기본 정렬: **최신순**
- 리스트 형태:
  - 질문 제목
  - 말머리/전공/태그 일부
  - 간단한 본문 요약
  - 추천 수, 답변 수, 조회수
  - 바운티 정보(있는 경우)

### 3.3 필터/정렬

홈 화면에서는 최소한 다음 옵션을 제공할 수 있다.

- 정렬:
  - 최신순(기본)
  - 추천순
- 필터:
  - 전공 필터 (내 전공만 보기 / 전체 보기)
  - 말머리 필터(예: 전공/학교생활/진로 등)

초기에는 **최신순 리스트만** 제공하고,  
필터/정렬은 티노인 전체 페이지에서 상세 제공하는 구조도 가능하다.

---

## 4. 하단 – 추천 티노스토리 카드

### 4.1 목적

- 사용자와 관련 있는 **모집/홍보 글(티노스토리)**을 자연스럽게 노출하여,
- QnA 참여뿐 아니라 실제 활동(스터디, 동아리 등) 참여로 이어지도록 한다.

### 4.2 노출 방식

- “추천 스토리” 섹션을 카드 형태로 구성
  - 카드 3개 내외 노출 + “더 보기” 버튼
- 각 카드에는 다음 정보 표시:
  - 모집글 제목
  - 모집 타입(동아리/스터디/프로젝트 등)
  - 대표 이미지
  - 모집 상태(모집중/모집완료/마감)
  - 마감 D-Day
  - 태그 일부
  - 작성자 정보

### 4.3 “나와 관련된 티노스토리” 기준

다음 기준 중 하나 이상을 만족하면 추천 대상으로 간주한다.

- 사용자의 전공/학부와 동일한 전공 태그 또는 전공 필드를 가진 모집글
- 사용자가 설정한 관심 태그와 겹치는 태그를 가진 모집글
- 사용자의 학년과 관련된 모집 대상(예: 1~2학년 대상, 졸업작품 팀원 모집 등)
- 사용자가 과거에 좋아요/북마크한 스토리와 태그/전공이 유사한 모집글

초기 버전에서는 **전공 + 관심사 태그** 기준만 사용해도 충분하다.

---

## 5. 공통 UX 및 제약사항

### 5.1 로그인 전제

- 서비스는 **로그인하지 않으면 사용할 수 없다.**
- 홈 화면 API 및 렌더링은 항상 “로그인된 사용자”를 기준으로 한다.
- 비로그인 사용자는 로그인/회원가입 화면으로 리다이렉트한다.

### 5.2 데이터 부족 시 처리

- 주목 질문/추천 스토리 후보가 부족할 경우:
  - 개인화 조건을 완화하여 전체 인기 질문/스토리를 노출한다.
  - 섹션을 숨기지 않고, “지금은 전체 인기 기준으로 보여드려요” 정도의 문구를 표시할 수 있다.

### 5.3 섹션 이동 경로

- 각 섹션에는 “전체 보기” 기능을 제공한다.
  - 주목 질문 전체 보기 → 티노인 추천/트렌딩 리스트 페이지
  - 새로 올라온 질문 더 보기 → 티노인 최신순 리스트 페이지
  - 추천 스토리 더 보기 → 티노스토리 피드 페이지

---

## 6. 알림(Notifications) 관련

- 현재 스코프에서는 **알림 기능을 제공하지 않는다.**
- 홈 화면 상단에 “알림 영역”은 두지 않으며,
  알림 기반 추천/뱃지 노출 등은 **추후 기능으로 별도 검토**한다.
- 추후 알림 기능 도입 시:
  - 내가 올린 질문/답변/스토리에 대한 변화(답변, 댓글, 모집 상태 변화 등)를  
    홈 화면과 어떻게 연동할지 별도 문서에서 정의한다.

---

## 7. 성능 및 구현 고려사항

- 홈 진입 시 필요한 데이터:
  - 개인화된 티노인 주목 질문 목록
  - 최신 질문 리스트
  - 개인화된 추천 티노스토리 목록
- 이를 위해 홈 전용 API를 설계하고,  
  추천/개인화 로직을 쿼리/캐시 레벨에서 최적화할 수 있다.
