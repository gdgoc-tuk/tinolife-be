# Auth 도메인 요구사항

## 1. 이메일 기반 로그인 및 회원가입

- 사용자는 이메일을 사용해 로그인과 회원가입을 진행할 수 있다.
- 회원가입 시 개인정보 보호 정책에 반드시 동의해야 한다.

## 2. 대학 이메일 도메인 제한

- 회원가입 시 사용자는 대학교 이메일을 사용해야 한다.
- 허용 도메인은 운영자가 정책에 따라 관리할 수 있다.
- 허용되지 않은 이메일 도메인 입력 시, 가입 불가 안내 메시지를 제공한다.

## 3. 이메일 인증 (코드 방식)

### 3.1 인증 코드 발급

- 회원가입 시 사용자가 입력한 이메일 주소로 인증 코드가 발송된다.
- 인증 코드는 숫자 6자리(예: 123456)와 같은 고유 값으로 생성한다.
- 인증 코드의 유효 시간은 운영 정책에 따라 설정한다(예: 5분).

### 3.2 인증 코드 입력

- 사용자는 회원가입 화면에서 이메일로 전달받은 인증 코드를 입력해야 한다.
- 코드가 일치하고 유효 시간 내인 경우 이메일 인증이 완료된다.
- 코드가 일치하지 않거나 만료된 경우 인증 실패로 처리한다.
- 인증 실패 시, 사용자에게 적절한 오류 메시지를 노출한다.

### 3.3 재전송 및 재시도 정책

- 사용자는 일정 횟수 내에서 인증 코드 재전송을 요청할 수 있다.
- 인증 코드 입력 시도 횟수는 보안 정책에 따라 제한할 수 있다.
- 재전송 요청 및 시도 횟수 초과 시, 잠금 또는 추가 보안 절차를 적용할 수 있다.

## 4. 기본 프로필 정보 입력

- 이메일 인증이 완료되면 사용자 정보 입력 단계로 이동한다.
- 사용자는 다음 정보를 필수로 입력한다:
  - 이름
  - 학년
  - 전공

## 5. 전공 정보 관리

- 전공 목록은 학교 홈페이지의 공식 리스트를 기반으로 한다.
- 운영자가 전공 목록을 추가, 수정, 비활성화할 수 있다.
- 사용자는 제공된 전공 목록에서 하나를 선택한다.

## 6. 관심사 키워드 설정

- 사용자는 관심사 키워드를 선택하여 개인 관심사를 설정할 수 있다.
- 관심사 키워드는 운영자가 추가, 수정, 비활성화할 수 있다.
- 관심사는 태그 형태로 제공되며 다중 선택을 지원한다.
