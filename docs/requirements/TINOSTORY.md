# TINO Story(티노스토리) 요구사항 문서

티노스토리는 인스타그램과 유사한 피드 형태로,  
사용자가 **스터디, 동아리, 프로젝트 등 모집/홍보 글**을 올릴 수 있는 기능이다.

---

## 1. 기능 개요

- 인스타그램 스타일 피드 UI
- 스터디/동아리/프로젝트 등 **모집·홍보 게시글** 등록
- 제목 + 본문 + 이미지 + 태그 + 모집 타입 + 모집 상태
- 오픈채팅 링크 공유 방식(내부 지원 기능은 없음)
- 좋아요, 북마크, 댓글 기능 제공
- 최신순, 마감 임박순 등 정렬
- 익명 불가(작성자 정보 노출)

---

## 2. 게시글 작성

### 2.1 필수 입력 항목

- 제목
- 본문 텍스트
- 모집 타입
  - 예: 동아리, 스터디, 프로젝트, 대외활동, 기타
- 모집 마감일
- 오픈채팅 링크(또는 외부 지원 링크)
- 모집 상태(초기값: 모집중)

### 2.2 선택 입력 항목

- 이미지(1장 이상 n장까지, 최대 개수는 정책으로 정의)
- 태그(자유 입력)
- 관련 참고 링크(선택)

### 2.3 익명 불가

- 티노스토리는 **홍보/모집 성격**이므로 익명 작성은 허용하지 않는다.
- 게시글에는 작성자의 프로필 정보가 표시된다.
  - 닉네임
  - (선택) 전공, 학년 등

---

## 3. 모집 상태 관리

티노스토리 게시글은 다음과 같은 **모집 상태**를 가진다.

### 3.1 상태 종류

- `모집중`
  - 기본 상태
  - 마감일이 아직 지나지 않았고, 작성자가 모집 완료 처리를 하지 않은 상태
- `모집완료`
  - 작성자가 더 이상 모집을 진행하지 않기로 결정한 상태
  - 마감일 이전이라도 수동으로 `모집완료`로 변경 가능
- `마감`
  - 설정된 모집 마감일이 지나면 자동으로 `마감` 상태로 변경
  - 작성자가 따로 조작하지 않아도 자동 처리

### 3.2 상태에 따른 동작

- `모집중`:
  - 피드 상단 및 기본 목록에서 우선 노출
  - 정렬 기준(최신순, 마감 임박순 등)에 포함
- `모집완료`, `마감`:
  - **조회는 가능**함
  - 기본 “모집중” 필터가 켜져 있을 때는 목록에서 제외
  - 사용자가 필터에서 “모집중만 보기” 옵션을 해제하면 함께 노출

---

## 4. 피드 조회 및 정렬

### 4.1 피드 구성

- 스크롤 기반 피드 UI로 게시글들을 카드 형태로 노출
- 각 카드에 노출되는 정보:
  - 제목
  - 대표 이미지(있을 경우)
  - 본문 일부(요약/더보기)
  - 작성자 정보
  - 모집 타입(동아리/스터디 등)
  - 모집 상태(모집중/모집완료/마감)
  - 남은 기간(모집중인 경우: D-3, D-7 등)
  - 좋아요 수, 댓글 수, 북마크 여부
  - 태그 리스트

### 4.2 정렬 기준

필수 제공 정렬 옵션:

- 최신순
- 마감 임박순(모집중인 글 기준)
- 인기순(좋아요 많은 순) — 도입 여부는 정책으로 조절 가능

정렬 시 기본적으로 **모집중 상태의 글**을 우선 대상으로 하며,  
필터 옵션에 따라 마감/모집완료 글 포함 여부를 선택할 수 있다.

### 4.3 상태 필터

- 기본값: `모집중만 보기` ON
  - 모집중 게시글만 목록에 노출
- 사용자가 `모집중만 보기`를 OFF 하면:
  - 모집완료, 마감 글도 함께 노출

---

## 5. 좋아요, 북마크, 댓글

### 5.1 좋아요

- 사용자는 게시글에 좋아요를 누를 수 있다.
- 한 사용자당 게시글별 좋아요는 최대 1회(토글 방식).
- 좋아요 수는 인기 정렬 및 신뢰도 지표로 사용 가능하다.

### 5.2 북마크

- 사용자는 관심 있는 모집글을 북마크할 수 있다.
- 북마크한 모집글은 마이페이지에서 별도로 확인 가능하다.

### 5.3 댓글

- 각 모집글에는 댓글 기능을 제공한다.
- 댓글은 간단한 문의/추가 질문/추가 안내 등에 활용된다.
- 댓글 구조:
  - 1단계 댓글 리스트(대댓글 구조는 추후 확장 가능)
- 댓글도 익명 불가이며 작성자 정보가 노출된다.

---

## 6. 태그

### 6.1 태그 입력

- 사용자는 모집글 작성 시 자유롭게 태그를 입력할 수 있다.
- 예: `#스터디`, `#알고리즘`, `#웹개발`, `#동아리`, `#공모전` 등

### 6.2 태그 활용

- 태그 기반 검색/필터링 제공
- 특정 태그를 클릭하면 해당 태그가 달린 모집글 목록으로 이동

### 6.3 태그 운영

- 초기에는 사용자 자유 입력 + 운영자 사후 검수(티노인과 동일 정책)
- 운영자는 중복/부적절 태그를 정리/병합할 수 있다.

---

## 7. 홍보/지원 방식

### 7.1 오픈채팅 링크 기반

- 티노스토리는 **내부 지원 시스템을 제공하지 않고**,  
  **단순 홍보 + 오픈채팅(또는 외부 링크) 기반**으로 모집을 진행한다.
- 게시글 작성 시 오픈채팅 URL 입력을 권장하며,  
  클릭 시 외부 채팅/폼으로 이동한다.

### 7.2 플랫폼 책임 범위

- 실제 지원/선발/운영은 오픈채팅 또는 외부 채널에서 진행되며,  
  티노스토리는 주로 **홍보와 연결** 역할만 담당한다.

---

## 8. 신고 및 운영

### 8.1 신고 대상

- 허위 모집
- 상업 광고, 스팸
- 불건전 내용, 규정 위반 표현 등

### 8.2 처리 정책

- 신고된 게시글은 운영자가 검토한다.
- 필요 시 게시글 숨김/삭제, 계정 제재를 단계적으로 적용한다.
- 반복 신고 계정에 대해 별도 모니터링을 수행한다.

---

## 9. 추가 고려 사항

아래 항목들은 향후 설계/운영 단계에서 추가로 논의가 필요한 부분이다.

### 9.1 모집 인원 및 참여 현황 노출 여부
- “모집 인원 n명”, “현재 지원자 수” 등을 표시할지 여부
- 오픈채팅 기반 구조상 정확한 지원자 집계가 어렵다는 점 고려 필요

### 9.2 공개 범위
- 전체 공개 / 학교 내부 공개 / 학과별 공개 등 권한/범위 설정 필요 여부

### 9.3 추천 알고리즘
- 전공, 태그, 사용자 관심사 기반 추천 피드
- 인기 모집글 영역 별도 노출

### 9.4 이미지 정책
- 최대 이미지 개수, 용량, 비율 제한
- 대표 이미지 자동 선택/직접 지정 여부

---

## 10. 연관 도메인 및 연계

- TINO-In(QnA)와 동일한 태그/전공 체계를 사용하는 방향을 고려
- TINO 토큰과 직접적인 연계(예: 모집글에 토큰을 거는 기능)는  
  현재 스코프에서는 제외, 추후 확장 시 논의
