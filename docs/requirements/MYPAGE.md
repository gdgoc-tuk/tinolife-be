# 마이페이지(My Page) 요구사항 문서

마이페이지는 사용자가 자신의 프로필 정보, 활동 이력, 토큰(TINO) 현황을
한 화면에서 확인·관리할 수 있는 공간이다.

---

## 1. 마이페이지 메인 구성

마이페이지는 크게 네 영역으로 구성한다.

1. 프로필 영역 (프로필 사진 및 기본 정보)
2. 활동 요약 영역 (질문/답변/스토리 통계)
3. TINO 토큰 현황 및 이력 영역
4. 내 활동 리스트 영역 (질문/답변/스토리 목록)

---

## 2. 프로필 영역

### 2.1 프로필 사진

- 사용자는 마이페이지 상단에서 자신의 프로필 사진을 확인할 수 있다.
- 프로필 사진 편집 기능 제공:
  - 새 이미지 업로드
  - 기존 이미지 변경
  - 프로필 사진 삭제(기본 이미지로 복귀)

### 2.2 기본 정보 표시

- 다음 사용자의 기본 정보를 마이페이지에서 확인할 수 있다.
  - 닉네임
  - 학교
  - 학년
  - 학과
- 기본 정보는 “프로필 편집” 화면을 통해 수정할 수 있다.
  - 학교/학과/학년의 수정 가능 범위는 정책에 따라 제한할 수 있다.

---

## 3. 활동 요약 영역

마이페이지 상단 또는 프로필 정보 하단에 **내 활동 이력 요약 카드**를 노출한다.

### 3.1 요약 지표

다음 항목들을 숫자로 요약해 보여준다.

- 내가 올린 질문 개수
- 내가 작성한 답변 개수
- 내가 작성한 답변 중 **채택된 답변 개수**
- 내가 올린 티노스토리(모집·홍보 글) 개수

---

## 4. TINO 토큰 현황 및 이력

### 4.1 현재 보유 TINO

- 사용자가 현재 보유한 TINO 토큰 수를 표시한다.
- 기본은 정수 단위로 표시한다.

### 4.2 TINO 획득/사용 이력 보기

- 마이페이지에서 **TINO 이력 보기** 섹션 또는 별도 화면으로 이동할 수 있는 진입점을 제공한다.
  - 예: “TINO 상세 이력 보기” 버튼

#### 4.2.1 이력 리스트 내용

각 TINO 이력 항목은 다음 정보를 포함한다.

- 일시 (YYYY-MM-DD HH:MM)
- 구분(타입)
  - 예: 출석 보상, 질문 등록 보상, 답변 등록 보상, 채택 보상, 이벤트 보상 등
- 증감 수량
  - +10 TINO / -5 TINO 형태
- 누적 잔액 (선택 사항, 추후 도입 가능)
- 간단 설명
  - 예: “출석 체크 보상”, “질문 바운티 채택 보상”, “이벤트 참여 보상”

#### 4.2.2 일자별 필터링

- 사용자는 TINO 이력을 **일자 기준으로 필터링**할 수 있다.
  - 시작일 ~ 종료일 형태의 기간 선택 필터 제공
  - 예: 2025-03-01 ~ 2025-03-31
- 자주 쓰는 기간에 대해 빠른 선택 옵션 제공 가능:
  - 최근 7일
  - 최근 30일
  - 전체
- 필터 적용 시, 선택한 기간에 해당하는 이력만 리스트에 표시된다.

#### 4.2.3 정렬 및 페이지네이션

- 기본 정렬: 최신순(가장 최근 이력이 상단)
- 이력 수가 많을 경우 페이지네이션 또는 무한 스크롤 중 하나를 선택해 적용한다.

---

## 5. 내 활동 리스트 영역

마이페이지에서는 사용자가 **직접 올린 콘텐츠**들을 리스트 형태로 확인할 수 있다.
탭 구조로 분리한다.

### 5.1 내가 올린 질문 리스트 (티노인)

- 탭명 예시: `내 질문`
- 리스트 항목 정보:
  - 질문 제목
  - 말머리(카테고리)
  - 전공/태그 일부
  - 등록일
  - 추천 수
  - 답변 수
  - 채택 여부
- 항목 클릭 시 해당 질문 상세 페이지로 이동.

### 5.2 내가 올린 답변 리스트 (티노인)

- 탭명 예시: `내 답변`
- 리스트 항목 정보:
  - 답변이 달린 질문 제목
  - 답변 내용 일부(요약)
  - 답변 작성일
  - 답변 좋아요 수
  - 답변 채택 여부
- 항목 클릭 시 질문 상세 + 내 답변 위치로 이동(또는 답변 상세 뷰).

### 5.3 내가 올린 스토리 리스트 (티노스토리)

- 탭명 예시: `내 스토리`
- 리스트 항목 정보:
  - 스토리 제목
  - 모집 타입(동아리/스터디/프로젝트 등)
  - 모집 상태(모집중/모집완료/마감)
  - 마감일(D-Day)
  - 좋아요 수, 댓글 수, 북마크 수
- 항목 클릭 시 해당 스토리 상세 페이지로 이동.

---

## 6. UX 및 기타 고려사항

### 6.1 정렬 및 필터 (선택)

- 각 리스트(내 질문/내 답변/내 스토리)에 대해 추후 정렬·필터 기능을 확장할 수 있다.
- 초기에는 최신순만 제공하고, 필요 시 이후 버전에서 확장한다.

### 6.2 프로필 편집 진입점

- 마이페이지 상단에 `프로필 편집` 버튼 배치.
- 프로필 편집에서 변경 가능한 항목:
  - 프로필 사진
  - 닉네임
  - (추후) 자기소개 등
- 학교/학과/학년 정보는 변경 허용 여부를 정책으로 정의한다.

### 6.3 접근 경로

- 헤더의 프로필 아이콘 또는 메뉴에서 마이페이지로 이동할 수 있다.
